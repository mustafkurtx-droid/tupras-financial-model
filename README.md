# TUPRS 3 Tablolu Finansal Model

Bu depo, TUPRS icin hazirlanmis dogrulanmis 3 tablolu finansal model dosyasini ve modelin koyu tema PDF sunumunu icerir.

## Icerik

| Dosya | Aciklama |
| --- | --- |
| `tupras_3_tablolu_model_tr_bagli_dogrulanmis.xlsx` | Gelir tablosu, bilanco ve nakit akisi tablolarini birbirine bagli olarak iceren dogrulanmis Excel modeli. |
| `TUPRS_koyu_tema_tam_dolgu_revize.pdf` | Model ciktisinin koyu tema, tam dolgu revize PDF sunumu. |

## Kullanim

Excel dosyasi uzerinden varsayimlar, finansal tablolar ve bagli hesaplamalar incelenebilir. PDF dosyasi ise modelin sunum veya hizli paylasim amacli gorunumudur.
